⚙️
Dynamic Tri-Cloud Workload Placement

Sleex dynamically dispatches tasks according to compute profile, consuming free serverless quotas across providers before touching the VPS hub:

  • No Shell (Reviews, Plans): Executed on Gateway (0 container cost).
  • Light Tasks (<12m): AWS Lambda (170 free runs/mo, 2 concurrent slots).
  • Heavy Builds (<30m): Google Cloud Run (free-tier high-memory compute).
  • Gated Container Jobs: Azure Container Apps (ACA) Jobs via ARM API (Microsoft.App/jobs).
  • Persistent Baseline / Fallback: Dedicated Oracle ARM VPS.
🔒
Encrypted Reverse SSH Tunneling

How does OpenClaw communicate with ephemeral Lambda, Cloud Run, and Azure containers behind NAT without opening public firewall ports?

  • Outbound-Only Tunnel: Ephemeral worker boots and initiates an outbound SSH reverse connection to edge.sleex.org via Cloudflare Access.
  • Cryptographic Authorization: sleex-edge verifies the lease token with Sleex API (box-key.mjs). If approved, it accepts the reverse socket.
  • Unix Domain Sockets: Reverse socket is exposed inside /run/sleex-boxes/<lease-id>.sock.
  • Zero Public Exposure: The Assistant SSHes into the local socket directly. The worker never exposes a public IP or open port!
SECURITY BENCHMARK: Zero Inbound Firewall Holes • All Ephemeral Workers Disposable • End-to-End Cryptographic Token Isolation
